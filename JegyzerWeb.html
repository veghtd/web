0. The basics (read this first)

In plain words, a web page has 3 parts:
🧱 HTML = WHAT is on the page (boxes, buttons, text, images)
🎨 CSS = HOW it looks (colors, size, position)
⚙️ JavaScript = WHAT HAPPENS when you click, type, or move the mouse

The skeleton – start EVERY task with this

The 5 golden rules of JavaScript

#RuleCode
1Anything JS needs to touch gets an id<input id="tipp">
2READ what the user typeddocument.getElementById("tipp").value
3WRITE text onto the pagedocument.getElementById("ki").innerHTML = "Hello";
4Inputs always give you TEXT, so turn it into a numberNumber(document.getElementById("tipp").value)
5A button runs a function<button onclick="tippel()">Tippel</button>
💡 Shortcut your teacher uses: if an element has id="tipp", you can just write tipp.value instead of document.getElementById("tipp").value. Both work. The long version is safer.
💡 Press F12 → Console in the browser. Red text there = your error and the line number.

Put display: flex on the BOX (the parent). Then two properties move what is inside:

⚠️ offsetX acting weird / jumping to small numbers? The mouse is over a CHILD element (like text inside the box), so offsetX is measured from that child. Fix: give the child pointer-events: none; in CSS, or put the child outside the tracked element.

6. The ruler: mouse goes 1 → 100, number at bottom middle, click = guess

The idea in plain words:
1. A box (position: relative) with a ruler image inside.
2. The ruler is e.g. 500px wide. The mouse X position on it (offsetX) is somewhere between 0 and 499.
3. Turn that into 1–100 with math.
4. Write the number into a label at the bottom middle of the box (position: absolute).
5. On click, put the number into the guess input and call the guess function.

A table = rows (tr), and every row has cells (td). So we need: a loop for the rows, and INSIDE it a loop for the cells.

Step 3 – Loop inside a loop

i = which ROW we are in. j = which COLUMN we are in. The cell value = i * j.

10. ⭐ Currency exchange (Pénzváltó)

How it works in plain words:
1. Read everything: name, amount, FROM currency (radio), TO currency (radio), discount (checkbox), fee (select)
2. Check for mistakes: empty name? amount ≤ 0? no currency picked? → show error, STOP
3. Convert FROM → forint → TO (every rate is "how many forints is 1 unit")
4. Add the fee, apply the discount if ticked
5. Show it with 2 decimals and a Hungarian comma

The formula explained with an example: 100 EUR → USD

StepCodeResult
EUR to forint (1 EUR = 363.6 Ft)100 * 363.636 360 Ft
forint to USD (1 USD = 323.1 Ft)36360 / 323.1112.54 USD
+2% fee112.54 * (1 + 2/100) = * 1.02114.79
-5% discount114.79 * 0.95109.05
💡 One line to memorize: atvaltott = osszeg * arfolyam(mirol) / arfolyam(mire);
"multiply by the FROM rate, divide by the TO rate". HUF has rate 1, so HUF → EUR is just / 363.6.
💡 Percent trick: +X% = * (1 + X/100). −X% = * (1 - X/100). So −5% = * 0.95, +2% = * 1.02. If your teacher says the fee is SUBTRACTED, use (1 - dij / 100).
